De-risk the git-native distributed claim/lease (docs/08 §8.5, HS2-11). Validate the atomic-push compare-and-swap claim marker against real remotes: (1) does a custom ref namespace (refs/hotsheet/claims/<ulid>) push + CAS-reject-on-conflict work on plain git remotes AND GitHub? GitHub is known to restrict arbitrary refs outside heads/tags. (2) Fallback: reserved-prefix TAGS (hs-claim/<ulid>) — confirm create-atomicity (second pusher rejected), --force-with-lease renew/steal, and bulk prune. Determine the recommended marker type per remote. Confirm lease payload location (annotated-tag message vs tiny object), expiry-based steal correctness under concurrency, and cleanup-sweep behavior. Output: a decision on ref-vs-tag + a tiny proof harness. See docs/08 §8.5.2.

## Notes

<!-- note: 01M0H6M3SZ9ZZ17404ARDXN79W -->
2026-08-19T04:08:49.628Z — **TL;DR: git-native claim/lease is validated. Decision — use a custom ref namespace `refs/hotsheet/claims/<ulid>` as the primary marker; tags are the documented fallback.**

### Mechanism proof (generic remote, local bare-repo harness)
All ✅: custom-ref CAS (2nd claimant rejected "fetch first"), tag CAS (2nd rejected "already exists"), `--force-with-lease` renew, **two-stealer race → exactly one wins** (stale stealer rejected "stale info"), `ls-remote` enumerate, and delete/sweep. Harness: `scratchpad/git-claim-spike.sh`.

### GitHub support (live test against the real Small-Tale/hotsheet2 remote)
**Surprise:** GitHub **ACCEPTS custom ref namespaces** — `refs/hotsheet/claims/*` pushed, listed via `ls-remote`, and deleted cleanly. Tags also accepted. Test refs were removed; origin verified clean. This contradicts the older "GitHub only allows refs/heads + refs/tags" lore — current behavior accepts arbitrary namespaces.

### Decision
- **Primary: custom ref `refs/hotsheet/claims/<ulid>`** — invisible to `git tag`/`branch` and the GitHub UI, bulk-prunable, doesn't touch `main` history or the working tree.
- **Fallback: reserved-prefix tags** for any remote that rejects custom refs (semantics identical).
- Payload `{worker, expires_at}` in the marker object (orphan commit / annotated-tag message), NOT the name. Renew/steal via `--force-with-lease=<ref>:<seen-oid>`.

### Caveats
- Claiming is **online** (needs a remote round-trip); custom refs aren't fetched by default, so the protocol explicitly `ls-remote`s/fetches the namespace.
- A concurrent push race **against GitHub specifically** wasn't stress-tested (it's a git server-side guarantee); worth a load test only if contention anomalies appear.
