# Frozen handoff advisory reviews (HS2-E20S6K)

An integrator can request up to two independent reviews of one frozen worker handoff while another handoff integrates or waits on gates. Reviewers have a separate identity and session token; they are not registered implementation workers and never acquire the ticket claim or main integration fence. The integrator still decides whether to return, integrate, push or complete the ticket.

Use `hotsheet-cli -C <store> coordination --project <main> advisory-request --id <integrator> --session <generation> --assignment <id> --reviewer <reviewer> --reviewer-session <token> --return-route <native:id|terminal:id|human>`. The result gives a durable request note id. Deliver that exact request through a supported addressed route or human relay. Recording a route does not wake an ended session. `advisory-cancel` with the request note id frees capacity for a lost or superseded request and invalidates any later result from it.

The addressed reviewer runs `advisory-review --id <reviewer> --session <token> --assignment <id>` to get a JSON snapshot. The snapshot binds the qualified ticket, assignment base, exact handoff and note, request note, ticket instruction digest, current main and full code tree (or a findings note without a tree). After read-only inspection, the reviewer supplies those fields plus `verdict`, a nonempty `summary`, and `findings` entries with `severity`, `evidence_ref` and `action` in a JSON file. `advisory-review --evidence-file <path>` preflights the file; `--publish` appends one regular advisory result note. Exact replay returns the same note. A changed result from the same reviewer on the same handoff is refused; the integrator can address another reviewer or return the handoff for correction.

Before integration, `advisory-inspect --id <integrator> --session <generation> --assignment <id> --note <result-id>` verifies the result against the current handoff, request, instructions, code tree and main. An unchanged main passes. A descendant main passes only when declared scope and changed paths are disjoint; unscoped or overlapping advancement requires a fresh review. Return or replacement of the handoff makes the old result stale. Review judgment is self-attested; the integrator resolves findings, checks the integration delta and runs the required integrated gate.

Request, result and cancellation notes provide durable timestamps for queue-delay and correction-round analysis. The HS2-34PWSK baseline has 55 matched handoffs, 11 matched review returns (20%), and a 34.8-minute median handoff-to-push span for 19 observed spans. Those observations do not establish active review time or a speedup. HS2-K1QNGC owns a live before/after measurement of review delay, correction rounds and the integrator's critical path.

The first implementation supports the local Markdown/Git ticket source. Other providers report the unsupported note capability explicitly. Reviewer sessions must be delivered by the host or a human; this CLI does not provide background agent launch or automatic wake.
